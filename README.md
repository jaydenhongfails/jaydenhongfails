## Featured projects

### [GEarth](https://github.com/liangricky7/GEarth)

A distributed simulation where 1,100 AI agents participate in economies across 10 fictional countries. I worked on the C# simulation engine and added [weekly snapshots for replay](https://github.com/liangricky7/GEarth/pull/27). At [Knight Hacks IX](https://devpost.com/software/diarockets), our team placed first in the BNY and Neon challenges and third in the AMD challenge.

**Stack:** C# · ASP.NET Core · Python · PyTorch · Neon PostgreSQL · Google Cloud

### [PFT Navigator](https://github.com/CSC-3380-Fall-2026/Team-16)

A 3D wayfinding tool for LSU’s Patrick F. Taylor Hall. I led the team and built [room previews for all 29 first-floor destinations](https://github.com/CSC-3380-Fall-2026/Team-16/pull/29).

**Stack:** Unreal Engine · Perforce · Python

### [Alfred](https://github.com/kennynguyen216/Alfred-AI-Student-Assistant)

A local AI assistant that summarizes email and extracts calendar events. It uses a four-stage LLM workflow, seven API endpoints, and vector search to recall relevant emails.

**Stack:** C# · ASP.NET Core · Entity Framework Core · SQLite · Ollama

### [Growga](https://github.com/jaydenhongfails/WICS-Hackathon2026)

A webcam yoga coach that scores five poses using 12 body landmarks. It runs LLaVA locally for feedback on how to adjust your form.

**Stack:** Python · MediaPipe · OpenCV · NumPy · Ollama
