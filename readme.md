## 👨‍💻 About Me

I'm a **Computer Science (Software Engineering)** undergraduate at [**Louisiana State University (LSU)**](https://www.lsu.edu/) based in Baton Rouge, LA. I focus on building practical full-stack web applications, autonomous AI agents, and interactive 3D/spatial systems.

* 🚀 **Startup Co-Founder:** Building a collaborative note-taking and study workflow mobile application for college students.
* 🤖 **AI & Agentic Systems:** Developing multi-tool AI agents and local LLM workflows using **C#**, [**Microsoft Semantic Kernel**](https://github.com/microsoft/semantic-kernel), **Microsoft Agent Framework**, [**LangChain**](https://www.langchain.com/), and [**Ollama**](https://ollama.com/) ([**OllamaSharp**](https://github.com/awaescher/OllamaSharp)).
* 🏗️ **Project Leadership:** Leading **Team 16** as Project Manager for the **LSU Patrick F. Taylor Hall (PFT) Digital Twin** in [**Unreal Engine**](https://www.unrealengine.com/), designing interactive room navigation, floor filtering, and optimized spatial map generation.
* 📊 **Full-Stack & Observability:** Crafting responsive web interfaces with [**Blazor**](https://dotnet.microsoft.com/en-us/apps/aspnet/web-apps/blazor) and [**Tailwind CSS**](https://tailwindcss.com/), backed by [**Prometheus**](https://prometheus.io/) and [**Grafana**](https://grafana.com/) telemetry dashboards.
* 🏸 **Campus Leadership:** Former Vice President of the **LSU Badminton Club**, organizing regional tournament logistics and helping bring LSU into the **Southeastern Collegiate Badminton Conference**.
